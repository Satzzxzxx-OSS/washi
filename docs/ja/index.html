Washi

Markdown・Typst・LaTeX・Mermaid・PDF を読むための macOS アプリです。ファイルが変わると描き直します。⌘E で、プレビューを見ながら編集もできます。

インストール · リリース

できること

  • Markdown・Typst・LaTeX・Mermaid・PDF を開きます。
  • 保存されると描き直し、スクロール位置はそのままです。読み込んでいるファイル（\input、#include、画像）の変更も追います。
  • ⌘E でプレビューの横にエディタを開き、入力に合わせてプレビューが変わります。Typst は補完とエラーの印つきです。
  • プレビューを ⌘ クリックするとソースの行へ移り、カーソルを動かすとプレビューも動きます。
  • ディスクのファイルが変わっていたら、上書きする前に確認します。未保存の変更には印が付きます。
  • ⌘K のコマンドパレットで、コマンド・最近のファイル・見出しを探せます。⌘F は一致の件数を表示します。
  • Typst はアプリの中でコンパイルします。LaTeX は latexmk か tectonic を使います。
  • washi file.md でターミナルから開けます。--json は安定した形式で結果を返します。
  • テレメトリはありません。通信するのは、Typst の @preview パッケージを取得するときだけです。

インストール

Apple Silicon の Mac のみ対応です。

brew install --cask kiwamizamurai/tap/washi
washi notes.md

リリースの zip をダウンロードして、アプリケーションフォルダに移す方法もあります。署名はしていないので、システム設定 → プライバシーとセキュリティで、一度だけ許可してください。
