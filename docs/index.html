Markdown · Typst · LaTeX viewer

Read quietly, on every save.

Markdown, Typst, LaTeX, Mermaid and PDF in one lightweight viewer. It redraws on every save while keeping your scroll position, and when you want to change something, press ⌘E for an editor with a live preview beside it.

Features

Reading first. Editing when you want.

It opens as a reader, so it starts fast and the screen stays quiet. The editor is loaded only when you ask for it.

Redraws the moment you save

It redraws as soon as your editor saves, keeping your reading position and zoom. Split chapters, bibliographies and images into separate files and saving any of them updates the view. You can follow an AI agent rewriting a file as it happens.

Edit with a live preview

Press ⌘E to split the window: your source on the left, the rendered result on the right, updating as you type. Syntax highlighting, search and replace, and for Typst, completion and error squiggles. Save with ⌘S; if the file changed on disk meanwhile, Washi asks instead of overwriting.

⌘-click to the source

⌘-click a Typst or LaTeX PDF (or Markdown) to jump to the matching line, in the built-in editor or your own (line and column for Typst, SyncTeX for LaTeX).

Outline and search

An outline panel that follows your position, PDF bookmarks included. ⌘F scrolls to each match automatically.

Math, code and diagrams

KaTeX math, highlighted code with a copy button, and Mermaid diagrams you can click to enlarge, then drag and scroll to pan and zoom.

Easy on the eyes

System, light and dark themes, adjustable text width, and zoom with ⌘+/− or pinch. Right-to-left text displays correctly too.

Paste or drop to read

⌘V detects Markdown, Typst, LaTeX or Mermaid from the clipboard, and dropping a file works too. Several files open in their own windows, and relative links are followed within Washi.

PDF, as it is

Text selection, search and a bookmark outline. Only pages near the viewport are drawn, so long PDFs open lightly.

Open it straight from an agent

washi report.typ opens the file and returns without waiting for the app. It supports --json output, validation beforehand, and stdin with cat draft.md | washi -, so you can check an agent's output at a glance.

Stays on your machine, errs on the safe side

Raw HTML inside documents is stripped and the app runs with a strict CSP. There is no telemetry or analytics. Washi itself only touches the network to fetch Typst @preview packages (the external tectonic may fetch TeX packages on its own).

How it works

Format differences hide behind one door.

  1. A Renderer handles each format, and the output is always either HTML or PDF.
  2. The UI only switches views by output type. To add a format, implement one Renderer and register it.
  3. External commands such as TeX sit behind a swappable interface, and tests use fakes.
  4. Rendering and the CLI live in washi-core, which does not depend on Tauri; the app itself (src-tauri) only handles the UI and windows.

Get started

One line with Homebrew.

For Apple Silicon macOS. The washi command and tectonic (for LaTeX) are installed together. Washi is not signed or notarized, so the Cask removes the quarantine attribute.

# Install with Homebrew (Apple Silicon)
$ brew install --cask kiwamizamurai/tap/washi
$ washi report.typ notes.md

# Run from source
$ git clone https://github.com/kiwamizamurai/washi
$ cd washi && pnpm install
$ pnpm tauri dev -- -- --gui examples/showcase.md

# Build the app (target/release/bundle/macos/Washi.app)
$ pnpm release
  • Open ⌘ O
